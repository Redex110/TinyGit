# TinyGit
TinyGit is a simplified version of Git. It is a simple project that I am building to test and apply my programming concepts and skills in practice.

`TinyGit` is intentionally lightweight and minimal and provides a small set of commands inspired by Git.

## Features

- Initialize a repository
- Stage files for commit
- Create commits with messages
- View repository history/logs
- Check staged or modified files
- Simple command-line interface in C

## Project status

This project is a learning focused implementation of Git. It is designed to help understand the basics of version control workflows in a small, understandable code base.
